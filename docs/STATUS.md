### 기반
- WXT 0.21 + TypeScript + React 19, 엔트리포인트 5개(background·filler·popup·options·sidepanel), `@webext-core/messaging`
- 테스트: Vitest 단위 테스트, Playwright E2E(`npm run test:e2e`, e2e 빌드 전용 호스트 권한 + fixture route 응답)

### 옵션 화면
- 이력서 입력·저장: 섹션 8개(기본 정보~희망 조건), 반복 항목 추가·삭제·순서 변경, 500ms 디바운스 자동 저장
- 자기소개서 라이브러리: 검색·태그 필터, 편집·복제·삭제, 글자수(공백 포함·제외·바이트)·제한 초과 경고
- 첨부 파일: 구분별 추가·삭제, 본문은 IndexedDB(첫 증명사진 = `basics.photo`)
- 학습 규칙 조회·삭제, 백업(JSON 내보내기/가져오기·미리 보기·전체 삭제)
- 설정: 제외 사이트(기본 linkedin.com + 사용자 도메인), 민감정보 자동 입력(기본 꺼짐)

### 매핑·형식 변환
- 매핑 순서: 학습 규칙 → autocomplete → 키워드 사전(섹션 문맥, 반복 블록 순서대로 인덱스)
- 섹션: 학력·경력·자격증·어학·수상·활동·프로젝트·병역·희망 조건, enum 항목은 옵션 동의어 사전 매칭
- 형식 변환: 생년월일·전화번호·연월·연월일(placeholder·maxLength·type=date 신호), 분리 입력(전화번호 3칸·연월일 칸), 입력 마스크 대응
- 민감정보 규칙(설정 켰을 때만), 파일 입력란 전용 규칙

### 위젯
- text·textarea·date, 기본 `<select>`, radio 그룹, 단일 checkbox, checkbox 그룹(다중 선택)
- ARIA 콤보박스(선택 전용, 열어서 선택지 읽기·portal 대응), 검색형 콤보박스(후보 확정)
- 파일 업로드(`DataTransfer`, accept 확인), 달력 팝업형 날짜 입력란(readonly 값 직접 설정, 1단계)

### 사이드 패널·학습
- 입력 결과(입력 완료·확인 필요·해당 없음) 목록, 복사, 직접 입력·선택지 선택, 이동, 위치 보기(하이라이트), 되돌리기, 다시 작성, 건너뛰기
- 학습: 직접 입력·선택지 선택·페이지에서 직접 고친 값(이력서 값과 같을 때) → `origin + fingerprint` 규칙 저장, 다음 '작성'에서 1순위
- 자기소개서 추천: 서술형 입력란별 유사 답변 3개(태그 + 문항 유사도), 글자수 제한 판별

### 프레임·권한
- 같은 출처 iframe 수집·입력(프레임별 fieldId)
- 교차 출처 iframe: `needs-permission` → 팝업 '접근 허용'(허용 시 background가 자동 재작성) / '이 페이지 부분만 입력'

### 검증
- 전체 코드 재검증(프레임 오류 처리·백업 가져오기 보완 등 수정)
- 실사용 검증(Claude in Chrome, 프로덕션 빌드 + 로컬 fixture·httpbin 교차 출처 폼): 팝업·옵션·사이드 패널·학습 흐름, 위젯 fixture 14종
- 단위 테스트 98개 · E2E 28개(fixture 18종) · 타입 검사·빌드 통과

## 결정 사항
| 항목 | 결정 | 근거 |
|---|---|---|
| 지향점 | 범용 확장 프로그램 (사이트별 어댑터는 예외 보정용) | 기업별 채용 페이지까지 커버 필요 |
| 매핑 방식 | 저장된 사용자 규칙 → 규칙/사전 기반 → (선택) BYOK LLM | 비용·개인정보 부담 최소화 |
| LLM | 원하는 사용자에 한해 본인 API 키 입력(BYOK) | Chrome 내장 AI(Gemini Nano) 한국어 미지원 |
| LLM 전송 범위 | 이력서 값 미전송, 스키마 키·필드 정보만 전송 | 개인정보 최소 전송 |
| 데이터 저장 | 로컬 저장, 개발자 서버 미사용 | 개인정보 처리 부담 최소화 |
| 제출 | 자동 제출 없음, 입력까지만 수행 | 오입력 방지, 사이트 약관 리스크 완화 |
| 기술 스택 | WXT + TypeScript + React | 빌드·멀티 브라우저·배포 자동화, 스키마·메시지 타입 관리, 폼 위주 화면 |
| 검증 사이트 | 사람인, 잡코리아, 링크드인 | 사용자 선정 (링크드인은 아래 미결 사항 참고) |

## 이슈·리스크
- 국내 사이트의 WAI-ARIA 준수율 미확인 → 범용 전략 효과 불확실
- 스크립트 이벤트(`isTrusted=false`)를 무시하는 위젯은 자동 입력 불가 → 사용자 직접 선택으로 대체
- 광고 등 보이는 크기의 교차 출처 iframe도 권한 안내 대상 → 실제 사이트에서 안내 빈도 확인 필요
- 교차 출처 '접근 허용' 거부 시 팝업이 닫혀 거부 안내 미표시 (다시 '작성' 시 같은 안내 표시). 허용 후 자동 재작성은 E2E로 대기 기록까지만 검증
- 사이드 패널 '다시 작성': activeTab은 툴바 클릭으로만 부여, 다른 출처로 이동 시 해제 → 이동 후에는 팝업 '작성' 필요
- 링크드인: 확장 프로그램 사용 시 계정 제한·정지 위험 명시
- 사람인·잡코리아 이용약관상 자동화 도구 제한 여부 미확인
