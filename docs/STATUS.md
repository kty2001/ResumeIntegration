### 최초 실행 동의
- 설치 직후 옵션 화면 자동 열림 → 동의 모달(데이터 처리 안내 + 확인 체크), 동의 전 팝업은 '확인하러 가기'만 표시
- `local:consent` 버전 비교로 문구 변경 시 재동의(v2: 가져오기 안내 추가), 개인정보처리방침 링크는 방침 작성 후 추가

### 옵션 화면
- 이력서 입력·저장: 섹션 8개(기본 정보~희망 조건), 반복 항목 추가·삭제·순서 변경, 500ms 디바운스 자동 저장
- 자기소개서 라이브러리: 검색·태그 필터, 편집·복제·삭제, 글자수(공백 포함·제외·바이트)·제한 초과 경고
- 첨부 파일: 구분별 추가·삭제, 본문은 IndexedDB(첫 증명사진 = `basics.photo`)
- 학습 규칙 조회·삭제, 백업(JSON 내보내기/가져오기·미리 보기·전체 삭제, 연동 사이트 포함)
- 설정: 제외 사이트(기본 linkedin.com + 사용자 도메인), 민감정보 자동 입력(기본 꺼짐)

### 매핑·형식 변환
- 매핑 순서: 학습 규칙 → autocomplete → 키워드 사전(섹션 문맥, 반복 블록 순서대로 인덱스)
- 반복 항목 블록 늘리기: 섹션별 이력서 항목 수가 페이지 블록보다 많으면 섹션 '추가' 버튼을 부족분만큼 클릭 → 새 입력란 대기 → 다시 수집 후 입력 (클릭 중 폼 제출 차단)
- 섹션: 학력·경력·자격증·어학·수상·활동·프로젝트·병역·희망 조건, enum 항목은 옵션 동의어 사전 매칭
- 형식 변환: 생년월일·전화번호·연월·연월일(placeholder·maxLength·type=date 신호), 분리 입력(전화번호 3칸·연월일 칸), 입력 마스크 대응
- 민감정보 규칙(설정 켰을 때만), 파일 입력란 전용 규칙

### 위젯
- text·textarea·date, 기본 `<select>`, radio 그룹, 단일 checkbox, checkbox 그룹(다중 선택)
- ARIA 콤보박스(선택 전용, 열어서 선택지 읽기·portal 대응), 검색형 콤보박스(후보 확정)
- ARIA 미준수 커스텀 드롭다운(잡코리아형): 트리거 버튼 + 형제 숨은 목록(`ul/ol > li`) + 형제 숨은 input → 콤보박스로 수집(라벨은 직전 형제 텍스트, 선택지는 열지 않고 읽음), 선택 후 표시 텍스트·숨은 input 값으로 검증, 미선택(숨은 input 빈 값)은 가져오기 제외
- 파일 업로드(`DataTransfer`, accept 확인), 달력 팝업형 날짜 입력란(readonly 값 직접 설정, 1단계)

### 사이드 패널·학습
- 입력 결과(입력 완료·확인 필요·해당 없음) 목록, 복사, 직접 입력·선택지 선택, 이동, 위치 보기(하이라이트), 되돌리기, 다시 작성, 건너뛰기
- 복사 전용 모드: 제외 사이트에서 팝업 '복사 전용 모드 열기' → 페이지 조작 없이 섹션별 이력서 항목 복사
- 학습: 직접 입력·선택지 선택·페이지에서 직접 고친 값(이력서 값과 같을 때) → `origin + fingerprint` 규칙 저장, 다음 '작성'에서 1순위 (fingerprint의 id는 6자리 이상 숫자열 정규화)
- 현장 조사 후속 보완: '전화번호'·'휴대폰' 공존 시 '전화번호'는 자택 전화, 라벨 텍스트 없는 select는 안내 선택지('대학구분 *')를 라벨로, 사전 '대학구분' 추가, 사이드 패널 저장 안내(섹션별 저장·자동 임시저장), 연동 사이트 추천(사람인·잡코리아 이력서 관리 페이지)
- 자기소개서 추천: 서술형 입력란별 유사 답변 3개(태그 + 문항 유사도), 글자수 제한 판별

### 이력서 가져오기·연동 사이트
- 가져오기: 팝업 '이 페이지에서 가져오기' → 이력서 수정 폼의 입력란 값 읽기 → '작성'과 같은 매핑으로 항목 결정 → 저장 형식 역변환(날짜·전화번호·분리 입력·숫자·선택지 → enum 코드) → 옵션 '가져오기' 미리 보기(빈 항목 기본 선택, 다른 값 기본 미선택, 반복 항목 갱신·추가 판별, 자기소개서 후보) → 선택 반영
- 연동 사이트: 옵션 메뉴에서 이력서 페이지 주소 등록·순서 변경, 팝업·옵션 '모두 열기'(새 창), '작성' 성공 시 마지막 작성 시각 기록 → 이력서 수정일과 비교해 '갱신 필요' 표시

### 프레임·권한
- 같은 출처 iframe 수집·입력(프레임별 fieldId)
- 교차 출처 iframe: `needs-permission` → 팝업 '접근 허용'(허용 시 background가 자동 재작성) / '이 페이지 부분만 입력'

### 검증
- 전체 코드 재검증(프레임 오류 처리·백업 가져오기 보완 등 수정)
- 실사용 검증(Claude in Chrome, 프로덕션 빌드 + 로컬 fixture·httpbin 교차 출처 폼): 팝업·옵션·사이드 패널·학습 흐름, 위젯 fixture 14종
- 가져오기·연동 사이트 실사용 검증: Playwright(동의 모달 재동의, 빈/기존 이력서 가져오기·취소, 입력란 없는 페이지, `formats`·`masks`·`sections` 왕복, 작성 시각·갱신 필요, 백업, 라이트/다크 화면 → 재동의·빈 이력서 가져오기·취소·왕복·갱신 필요·백업 연동 사이트는 E2E에 추가) + 실제 Chrome(툴바 가져오기 → 미리 보기 탭, 제외 사이트 안내, 모두 열기·작성 후 '최신') → 연월만 받는 입력란에서 읽은 날짜가 현재 연월일과 같은 달이면 같은 값으로 처리하도록 수정
- 잡코리아 실제 확인(커스텀 드롭다운 대응 후): '작성' 입력 완료 7 → 8(성별), 스크립트 이벤트로 선택·숨은 input 갱신 동작, 자동 임시저장 타이머 해제 후 저장 없이 이탈
- 단위 테스트 120개 · E2E 41개(fixture 22종) · 타입 검사·빌드 통과

## 결정 사항
| 항목 | 결정 | 근거 |
|---|---|---|
| 지향점 | 범용 확장 프로그램 (사이트별 어댑터는 예외 보정용) | 기업별 채용 페이지까지 커버 필요 |
| 매핑 방식 | 저장된 사용자 규칙 → 규칙/사전 기반 → (선택) BYOK LLM | 비용·개인정보 부담 최소화 |
| LLM | 원하는 사용자에 한해 본인 API 키 입력(BYOK) | Chrome 내장 AI(Gemini Nano) 한국어 미지원 |
| LLM 전송 범위 | 이력서 값 미전송, 스키마 키·필드 정보만 전송 | 개인정보 최소 전송 |
| 데이터 저장 | 로컬 저장, 개발자 서버 미사용 | 개인정보 처리 부담 최소화 |
| 제출 | 자동 제출 없음, 입력까지만 수행 | 오입력 방지, 사이트 약관 리스크 완화 |
| 기술 스택 | WXT + TypeScript + React | 빌드·멀티 브라우저·배포 자동화, 스키마·메시지 타입 관리, 폼 위주 화면 |
| 검증 사이트 | 사람인, 잡코리아, 링크드인 | 사용자 선정 (링크드인은 아래 미결 사항 참고) |
| 이력서 가져오기 범위 | 사이트의 이력서 수정 폼 입력값 읽기 우선, 열람 페이지는 후속 | 기존 수집·매핑 엔진 재사용, 범용 원칙 유지 ([architecture](design/architecture.md) 7.4) |
| 열람 페이지 가져오기 방식 | 범용 라벨-값 추출 우선, 범용 처리 불가 사이트만 사이트별 어댑터 | 범용 지향 + 어댑터는 예외 보정용 원칙 ([architecture](design/architecture.md) 7.4) |
| 가져오기 동의 안내 | 최초 실행 동의 문구에 가져오기(페이지 입력값 읽기) 안내 추가, `CONSENT_VERSION` 증가로 기존 사용자 재동의 | 페이지 데이터 수집 사실 고지 |
| 가져오기 반영 방식 | 미리 보기 후 항목별 선택 반영 (반복 항목은 같은 항목 판별 → 갱신·추가) | 기존 이력서 덮어쓰기·오인식 값 저장 방지 |
| 사람인·잡코리아 처리 | 자동 입력 대상 유지 (제외 사이트 미추가) | 약관상 확장 프로그램·자동화 명시 금지 없음, 포괄 조항(업무 지장·정보 유용)만 존재 ([05](reports/05_privacy_and_policy.md) 4.2) |
| 달력 탐색 클릭 | 구현 안 함 | 사람인·잡코리아 모두 날짜 텍스트 직접 입력 가능 ([07](reports/07_site_dom_survey.md)) |
| 커스텀 드롭다운 | ARIA 미준수 패턴(버튼 + 목록 + 숨은 input)을 범용 규칙으로 추가 | 잡코리아 선택 항목 전부 해당, 사이트 전용 어댑터 대신 범용 패턴 ([07](reports/07_site_dom_survey.md) 4장) |
| 커스텀 드롭다운 후속 | 보류: 숨은 input 없는 선택 UI(잡코리아 학교구분), 목록 안 checkbox 다중 선택형(고용형태) | 학교구분은 선택 시 입력 폼이 바뀌는 UI라 사용자 직접 선택 후 '다시 작성'으로 충분, 고용형태는 희망 조건 1항목 |
| 열람 페이지 가져오기 (재조사 후) | 범용 `readPairs` 보류, 수정 폼 가져오기 보완 우선 | 반복 항목(학력 등)이 두 사이트 모두 라벨 없는 묶음 텍스트 → 범용 추출 불가, 어댑터 필요 ([07](reports/07_site_dom_survey.md) 6.3) |
| 연동 사이트 기본 추천 | 사람인·잡코리아 이력서 관리 페이지 | 수정 페이지 URL에는 이력서 번호 포함 ([07](reports/07_site_dom_survey.md)) |
| 연동 사이트 작성 방식 | 등록 URL 일괄 열기만 + 탭별 툴바 '작성', 로그인은 사용자 직접 | 권한 추가 없음(activeTab 유지), 탭별 결과 검토 ([architecture](design/architecture.md) 7.5) |

## 이슈·리스크
- 국내 사이트 WAI-ARIA 준수: 잡코리아 커스텀 드롭다운은 ARIA 미준수 → 구조 패턴(버튼 + 숨은 목록 + 숨은 input)으로 대응, 잡코리아 성별에서 동작 확인. 숨은 input 없는 학교구분(폼 전환 UI)·checkbox 목록형 고용형태는 미인식(보류, 사용자 직접 선택)
- 잡코리아 최초 작성 페이지 5분 자동 임시저장 → '작성' 후 저장하지 않아도 채운 값이 임시저장될 수 있음
- 사람인 입력란 id 시각값 접미사: fingerprint에서 6자리 이상 숫자열 정규화로 대응. 기존에 저장된 긴 숫자 id 규칙은 더 이상 매칭되지 않음(원래 재사용 불가였던 규칙)
- '전화번호' 단독 입력란은 여전히 휴대폰으로 처리 (휴대폰 입력란이 함께 있을 때만 자택 전화)
- 스크립트 이벤트(`isTrusted=false`)를 무시하는 위젯은 자동 입력 불가 → 사용자 직접 선택으로 대체
- 광고 등 보이는 크기의 교차 출처 iframe도 권한 안내 대상 → 실제 사이트에서 안내 빈도 확인 필요
- 교차 출처 '접근 허용' 거부 시 팝업이 닫혀 거부 안내 미표시 (다시 '작성' 시 같은 안내 표시). 허용 후 자동 재작성은 E2E로 대기 기록까지만 검증
- 사이드 패널 '다시 작성': activeTab은 툴바 클릭으로만 부여, 다른 출처로 이동 시 해제 → 이동 후에는 팝업 '작성' 필요
- 링크드인: 확장 프로그램 사용 시 계정 제한·정지 위험 명시
- 사람인·잡코리아 이용약관: 자동화 명시 금지 없음, 단 포괄 조항(업무 지장·서비스로 얻은 정보 복제·유용)에 따른 제재는 회사 판단 영역 → 대량·반복 동작 추가 금지, 사람인 별도 '서비스 운영정책' 미확인
- 가져오기 정확도: 매핑 오인식 시 다른 항목에 값 저장 위험 → 미리 보기에서 사용자 확인, 기존 값과 다른 항목은 기본 미선택
- 반복 항목 '추가' 버튼: 표시 텍스트 휴리스틱 → 아이콘만 있는 버튼·모달로 항목을 추가하는 사이트는 미인식(기존 블록만 입력), 실제 사이트 확인 필요
- '되돌리기'는 입력값만 복원, '추가' 버튼으로 늘린 블록은 남음
- 가져오기 갱신 판별은 대표 항목(학교명 등) 표기 일치 기준 → 사이트마다 표기가 다르면('OO대' vs 'OO대학교') 추가로 판별, 미리 보기에서 해제 필요
- Claude in Chrome은 확장 프로그램 페이지(옵션·팝업) 조작 불가 → 화면 검증은 Playwright, 툴바·activeTab 동작만 실제 Chrome에서 사용자 조작
- 가져오기는 이력서 수정 폼 대상 → 입력란 없는 열람 페이지는 'empty' 안내. 사람인 수정 페이지도 보기 모드라 'empty' → 섹션별 '수정하기' 후 가져오기 필요(섹션당 1블록)
- 사람인 학력구분·잡코리아 학교구분 선택 시 학력 폼을 다시 그림 → 현재 '작성'은 나머지 학력 입력란을 '입력란을 찾을 수 없음'으로 처리
- 학교명·전공명 자동완성(두 사이트): 목록에서 고르지 않은 값은 사이트가 지움 → 현재 '작성'은 입력 완료로 표시되어도 저장 시 빈 값 가능
- 잡코리아 자유형 자기소개서(제목 + 내용)는 '해당 없음'·추천 없음
- 테스트 이력서(사람인 비공개 '확장프로그램 조사용 테스트 (삭제 예정)', 잡코리아 1건)는 사용자 삭제 필요
