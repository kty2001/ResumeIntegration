# 화면 설계 v1

최종 갱신: 2026-10-12 · 관련 문서: [architecture.md](architecture.md)

- 와이어프레임 수준 정적 HTML 목업, 로컬에서 파일을 직접 열어 확인 (외부 리소스 없음)
- 입력 항목은 [04 보고서](../reports/04_target_sites_and_data_model.md) 3장 기준으로 작성. 스키마 v1과의 차이는 [resume_schema_v1.md](resume_schema_v1.md) 10장
- 표시 데이터는 모두 가상 값
- 실제 화면 스타일은 [style_guide.md](style_guide.md) 기준 (견본 [style.html](mockups/style.html)). 표의 '구현' 열·(미구현) 표시로 목업 대비 기능 현황 구분

## 2. 팝업 (폭 360px)

| 상태 | 조건 | 표시 | 주요 동작 | 구현 |
|---|---|---|---|---|
| ⓪ 동의 전 | 최초 실행 동의(`local:consent`) 없음·버전 다름 | 안내 문구 | '확인하러 가기' → 옵션 화면 동의 모달 ('작성' 미표시) | ● |
| ① 작성 가능 | 이력서 있음 + 일반 사이트 | 이력서 요약(이름·수정일), 이력서 선택 목록(항상 표시, 변경 시 선택된 이력서 변경) | '작성' → `startFill` + 사이드 패널 열기, 결과 개수 문구 | ● (현재 도메인·항목 수 표시 없음) |
| ② 이력서 미입력 | 저장된 이력서 없음 | 안내 문구 | '이력서 입력하러 가기' → 옵션 / 'JSON 가져오기' → `options.html#backup` | ● |
| ③ 제외 사이트 | 기본·사용자 제외 목록 (예: linkedin.com), 팝업 열 때 탭 URL로 판정 | 현재 호스트·제외 사유 문구 | '복사 전용 모드 열기' → 사이드 패널 ② ('작성' 비활성) | ● |
| ④ 권한 필요 | `startFill` 응답 `needs-permission` (교차 출처 iframe) | 필요한 출처 | '접근 허용' → `permissions.request`(허용 시 background가 재작성) / '이 페이지 부분만 입력' | ● |
| ⑤ 입력 중 | 작업 진행 | 진행률 | 대기 | '입력 중…' 버튼 표시만 |
| ⑥ 가져오기 | ①·② 상태(제외 사이트 아님)에서 '이 페이지에서 가져오기' | 결과 문구(읽은 항목 수·읽은 값 없음) | `startImport` → 성공 시 옵션 '가져오기' 새 탭 ([architecture.md](architecture.md) 7.4) | ● |

- 공통 하단: '이력서 편집'(옵션 열기). '도움말'은 미구현
- 공통 하단: '연동 사이트 모두 열기'(동의 후·등록 사이트 있을 때, '갱신 필요' 사이트 수 표시) → 새 창에 일괄 열기 ([architecture.md](architecture.md) 7.5)
- 사이드 패널 열기는 팝업 클릭 처리 안에서 호출 (사용자 제스처 필요, [architecture.md](architecture.md) 10장)

## 3. 사이드 패널 (폭 400px)

### ① 입력 결과
- 요약: 입력 완료 / 확인 필요 / 해당 없음 개수 (`fillReport`)
- 상단 동작: '입력 항목 위치 보기'(상태별 색 테두리 토글: 초록 입력 완료·주황 확인 필요·회색 해당 없음), '되돌리기' → `undo`, '다시 작성' → `startFill`(activeTab이 남아 있는 같은 출처에서만 동작)
- 저장 안내(고정): 입력만 수행, 사이트 저장 버튼(섹션별 저장 포함)을 눌러야 반영, 일부 사이트는 자동 임시저장
- 확인 필요 항목 카드 — 실패 유형별 처리

| 유형 | 표시 | 동작 |
|---|---|---|
| 매핑 실패 (텍스트) | 실패 사유, 이력서 항목 선택 목록 | '입력' → `fillOne` / '건너뛰기'(확인 필요 → 해당 없음) |
| 선택지 불일치 (드롭다운) | 저장 값 표시명, 사이트 선택지 목록 | '선택' → `fillOne { optionValue }`, 성공 시 자동 학습 ('이 선택 기억하기' 체크 없음) |
| 위젯 입력 불가 (달력 등) | 사이트 형식으로 변환한 값 | '복사', '이동' → `focusField` |
| 자기소개서 ('자기소개서 추천') | 미입력 서술형 입력란별 유사 답변 최대 3개, 글자수/제한·초과 표시 | '미리 보기', '입력' → `fillAnswer` |

### ② 복사 전용 모드
- 제외 사이트에서 사용, 페이지 조작 없음 (content script 미주입). 팝업이 `session:copyOnly` 저장 후 사이드 패널 열기, '작성' 시 background가 해제
- 이력서 섹션별 접이식 목록('기본 정보', '학력 1' …) + 항목별 '복사' — 입력 결과 화면 하단 '이력서 항목 복사'와 같은 목록

## 4. 옵션 (이력서 편집)

| 메뉴 | 내용 |
|---|---|
| 기본 정보 | 이름(한글·영문·한자), 생년월일, 연락처, 주소, URL, 증명사진 |
| 학력 | 반복 카드: 학교 구분, 학교명(국문·영문), 입학·졸업, 졸업 상태, 전공, 학점 + 만점 기준, 편입 |
| 경력 | 반복 카드: 회사명(국문·영문), 고용 형태, 부서, 직급·직책, 기간, 재직 중, 연봉, 퇴사 사유, 담당 업무 |
| 병역·취업우대 | 병역 정보 / 보훈·장애(민감정보 표시·안내) |
| 어학·자격증 | 표 형태 목록 + 추가 |
| 활동·수상 | 구분(수상·대외활동·교육)별 목록 |
| 프로젝트·기술 | 프로젝트 반복 카드, 보유 기술 |
| 희망 조건 | 희망 연봉(회사 내규 옵션), 근무지, 입사 가능일 |
| 자기소개서 | 문항·답변 라이브러리: 검색·태그 필터, 글자수 제한 기준(공백 포함·제외·바이트), 실시간 글자수 |
| 첨부 파일 | 구분(증명사진·이력서·포트폴리오·성적증명서·증명서·기타) 선택 후 추가·삭제, 본문 없음 표시 |
| 설정 | 제외 사이트 관리(기본 목록 + 사용자 도메인), 민감정보 자동 입력(기본 꺼짐). 학습 여부·LLM 보조(제공자·API 키 마스킹·동의)는 미구현 |
| 학습 규칙 | 사이트·입력란·이력서 항목·선택지·수정일, 삭제 |
| 백업 | JSON 내보내기/가져오기(미리 보기 → 덮어쓰기, API 키·첨부 본문 제외), 전체 삭제(확인 단계) |
| 연동 사이트 | 이름·이력서 수정 페이지 URL 추가(형식·중복 확인)·삭제·순서 변경, 사이트별 마지막 작성일·'갱신 필요' 표시, '모두 열기'·개별 열기. 제외 사이트 URL은 등록 후 '복사 전용 모드로 사용' 안내. 기본 추천: 미등록 추천 사이트(사람인·잡코리아 이력서 관리 페이지)를 '추천 · OO 추가' 버튼으로 표시 |
| 가져오기 | 아래 '가져오기 미리 보기' 참고 (가져온 내용 없으면 사용 방법 안내) |

- 이력서 여러 개: 상단 바에서 이력서 선택(= '작성' 대상)·이름 변경·'새 이력서'(빈 이력서)·'복제'(첨부 파일 본문 포함 복사)·'삭제'(확인 단계, 첨부 파일 본문도 삭제). 자기소개서·학습 규칙·연동 사이트·설정은 공용
- 저장 방식: 입력 즉시 자동 저장 (`local:resumes` 등, [architecture.md](architecture.md) 8장)
- 반복 항목 순서 변경: 위·아래 버튼 방식 (결정)

### 가져오기 미리 보기
- 출처: 가져온 페이지 호스트·시각 (`session:importDraft`)
- 섹션별 표: 항목 · 현재 값 · 가져온 값 · 선택(체크)
  - 현재 값 비어 있음 → 기본 선택 / 값 다름 → 기본 미선택 / 값 같음 → 표시 생략
  - 반복 항목(학력·경력 등): 카드 제목에 '학력 · 학교명 (갱신)' 또는 '(추가)' 표시, 대표 항목(학교명 등) 없이 추가되는 카드는 기본 미선택
  - 역변환 실패 값: 원문 표시 + '확인 필요', 기본 미선택
- 자기소개서 후보: 문항·답변 미리 보기, 선택 시 라이브러리에 추가
- '선택 항목 반영 (n)' → 선택 항목만 저장, 완료 문구 표시 / '모두 선택' → '확인 필요' 제외 전 항목 선택 (모두 선택 상태면 비활성) / '취소' → draft 삭제

## 5. 동의 모달
- ① 최초 실행 (구현): 로컬 저장, 클릭한 탭에서만 동작, 자동 제출 없음, 서버 전송 없음, 민감정보 기본 꺼짐 + '위 내용을 확인했습니다' 체크 → '시작하기'
  - 설치 직후 옵션 화면 자동 열림, 동의 전 옵션 화면은 모달로 가림(닫기 없음), 팝업은 ⓪ 동의 전 상태
  - 동의 = `local:consent.version`이 `CONSENT_VERSION`과 같음 → 문구 변경 시 버전 올려 재동의. 백업 '전체 삭제' 후에도 유지
  - 개인정보처리방침 링크는 방침 작성(배포 단계) 시 추가
  - 가져오기 안내 포함: '가져오기'를 누른 페이지의 이력서 값을 읽어 이 브라우저에만 보관, 미리 보기에서 고른 항목만 반영 → `CONSENT_VERSION` 2 (기존 사용자 재동의)
- ② LLM 보조 첫 사용 (미구현, BYOK와 함께): 보내는 정보 / 보내지 않는 정보 표, 전송 예시, 요금 부담 주체 안내 + 동의 체크
- 문구는 초안, 개인정보처리방침 작성 시 확정 ([05 보고서](../reports/05_privacy_and_policy.md))
