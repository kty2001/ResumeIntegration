# 화면 설계 v1

최종 갱신: 2026-10-07 · 관련 문서: [architecture.md](architecture.md)

- 와이어프레임 수준 정적 HTML 목업, 로컬에서 파일을 직접 열어 확인 (외부 리소스 없음)
- 입력 항목은 [04 보고서](../reports/04_target_sites_and_data_model.md) 3장 기준으로 작성. 스키마 v1과의 차이는 [resume_schema_v1.md](resume_schema_v1.md) 10장
- 표시 데이터는 모두 가상 값

## 1. 화면 목록

| 화면 | 목업 | 진입 경로 | 역할 |
|---|---|---|---|
| 팝업 | [popup.html](mockups/popup.html) | 툴바 아이콘 클릭 | 현재 사이트 상태 확인, '작성' 실행 |
| 사이드 패널 | [sidepanel.html](mockups/sidepanel.html) | '작성' 완료 시 자동, 팝업 버튼 | 입력 결과 확인, 미입력 항목 직접 처리, 복사 전용 모드 |
| 옵션 (이력서 편집) | [options.html](mockups/options.html) | 팝업 '이력서 편집'·'설정', 확장 프로그램 관리 화면 | 이력서 입력·관리, 설정, 학습 규칙, 백업 |
| 동의 모달 | [consent.html](mockups/consent.html) | 최초 실행, LLM 보조 첫 사용 | 개인정보 안내·동의 |

## 2. 팝업 (폭 360px)

| 상태 | 조건 | 표시 | 주요 동작 |
|---|---|---|---|
| ① 작성 가능 | 이력서 있음 + 일반 사이트 | 현재 도메인, 이력서 요약(이름·수정일·항목 수) | '작성' → `startFill` / '사이드 패널 열기' |
| ② 이력서 미입력 | 저장된 이력서 없음 | 안내 문구 | '이력서 입력하러 가기' → 옵션 / 'JSON 가져오기' |
| ③ 제외 사이트 | `site-policy` 제외 목록 (예: linkedin.com) | 제외 사유 | '복사 전용 모드 열기' → 사이드 패널 ②, '작성' 비활성 |
| ④ 권한 필요 | `startFill` 응답 `needs-permission` (교차 출처 iframe) | 필요한 출처 | '접근 허용' → `permissions.request` / '이 페이지 부분만 입력' |
| ⑤ 입력 중 | 작업 진행 | 진행률 | 대기 (완료 시 사이드 패널로 결과 전달) |

- 공통 하단: '이력서 편집'(옵션 열기), '도움말'
- 사이드 패널 열기는 팝업 클릭 처리 안에서 호출 (사용자 제스처 필요, [architecture.md](architecture.md) 10장)

## 3. 사이드 패널 (폭 400px)

### ① 입력 결과
- 요약: 입력 완료 / 확인 필요 / 해당 없음 개수 (`fillReport`)
- 상단 동작: '입력 항목 위치 보기'(하이라이트 표시), '되돌리기' → `undo`, '다시 작성' → `startFill`
- 확인 필요 항목 카드 — 실패 유형별 처리

| 유형 | 표시 | 동작 |
|---|---|---|
| 매핑 실패 (텍스트) | 실패 사유, 이력서 항목 선택 목록 | '입력' → `fillOne` / '건너뛰기' |
| 선택지 불일치 (드롭다운) | 저장 값, 사이트 선택지 목록, '이 선택 기억하기' | '선택' → `fillOne` + 학습 규칙 저장 |
| 위젯 입력 불가 (달력 등) | 사이트 형식으로 변환한 값 | '복사', '입력란으로 이동' → `focusField` |
| 자기소개서 | 유사 문항 답변 후보, 글자수·초과 경고 | '미리 보기', '입력' → `fillOne` |

- 구현 현황 (`src/entrypoints/sidepanel/`): 요약, 확인 필요·입력 완료·해당 없음 목록, '되돌리기', 확인 필요·해당 없음 행의 이력서 항목 선택 + '입력'·'이동', '복사'. 하이라이트·'다시 작성'·'건너뛰기'·학습은 후속

### ② 복사 전용 모드
- 제외 사이트에서 사용, 페이지 조작 없음 (content script 미주입)
- 이력서 섹션별 접이식 목록 + 항목별 '복사'

## 4. 옵션 (이력서 편집)

| 메뉴 | 내용 |
|---|---|
| 기본 정보 | 이름(한글·영문·한자), 생년월일, 연락처, 주소, URL, 증명사진 |
| 학력 | 반복 카드: 학교 구분, 학교명(국문·영문), 입학·졸업, 졸업 상태, 전공, 학점 + 만점 기준, 편입 |
| 경력 | 반복 카드: 회사명(국문·영문), 고용 형태, 부서, 직급·직책, 기간, 재직 중, 연봉, 퇴사 사유, 담당 업무 |
| 병역·취업우대 | 병역 정보 / 보훈·장애(민감정보 표시·안내) |
| 어학·자격증 | 표 형태 목록 + 추가 |
| 활동·수상 | 구분(수상·대외활동·교육)별 목록 |
| 희망 조건 | 희망 연봉(회사 내규 옵션), 근무지, 입사 가능일 |
| 자기소개서 | 문항·답변 라이브러리: 검색·태그 필터, 글자수 제한 기준(공백 포함·제외·바이트), 실시간 글자수 |
| 첨부 파일 | 이력서·포트폴리오 파일 |
| 설정 | 자동 입력 옵션(민감정보 입력 여부, 학습 여부), LLM 보조(제공자·API 키 마스킹·동의), 제외 사이트 관리 |
| 학습 규칙 | 사이트·입력란·이력서 항목·선택지·수정일, 삭제 |
| 백업 | JSON 내보내기/가져오기(API 키 제외), 전체 삭제 |

- 저장 방식: 입력 즉시 자동 저장 (`local:resume` 등, [architecture.md](architecture.md) 8장)
- 반복 항목 순서 변경: 위·아래 버튼 방식 (결정)
- 구현 현황 (`src/entrypoints/options/`): 기본 정보, 학력, 경력, 병역·취업우대, 어학·자격증, 활동·수상, 프로젝트·기술, 희망 조건, 학습 규칙(사이트·입력란·이력서 항목·수정일, 삭제. 선택지 열은 드롭다운 학습 구현 시 추가) 구현. 자기소개서·첨부 파일·설정·백업은 후속

## 5. 동의 모달
- ① 최초 실행: 로컬 저장, 클릭한 탭에서만 동작, 자동 제출 없음, 서버 전송 없음, 민감정보 기본 꺼짐 + 개인정보처리방침 확인 체크
- ② LLM 보조 첫 사용: 보내는 정보 / 보내지 않는 정보 표, 전송 예시, 요금 부담 주체 안내 + 동의 체크
- 문구는 초안, 개인정보처리방침 작성 시 확정 ([05 보고서](../reports/05_privacy_and_policy.md))

## 6. 미결 사항
- 실제 컴포넌트·디자인 적용 (React 구현 시)
- 증명사진·첨부 파일 저장 용량 (`storage.local` 10MB 한도, `unlimitedStorage` 필요 여부)
